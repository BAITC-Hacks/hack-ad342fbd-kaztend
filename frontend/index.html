Карта районов схема

Схематичные полигоны по реальной географии: границы районов — условные. Цвет — оценка района, подпись — доля населения. Нажмите на район.

Показатели районов

5 районов × 10 показателей. Цвет — значение (0–100, больше — лучше), стрелка — изменение, рамка — критическое значение (<40). Наведите или нажмите на ячейку: вклад каждой меры.

Формула Astana Quality of Life Score

I′dk = clip( Idk + Σm effectm,k × (H − Lm)/H + синергии, 0, 100 )
Dd = Σk wk · I′dk    Davg = Σd popd · Dd
Score = 0.7 · Davg + 0.3 · mind(Dd) − 1.0 · Ncrit   

Гибридная агрегация по ТЗ: линейная часть 0.7·D_avg + роулсианский член 0.3·min D + штраф за значения <40. Формула не менялась; аналитика проверяет её робастность (OECD/JRC 2008).
