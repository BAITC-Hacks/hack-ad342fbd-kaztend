# Методология

## 1. Модель Astana Quality of Life Score (по ТЗ спец-трека Astana Innovations)
- 5 условных районов × 10 показателей (шкала 0–100, «больше — лучше»), веса показателей w_k (транспорт 0.20, экология 0.20, соцсфера 0.22, безопасность 0.18, сервисы 0.20).
- 14 мероприятий с типом (район/город), стоимостью, лагом L и эффектами; реализованная доля эффекта = (8 − L)/8 при горизонте 8 кварталов; 3 синергии, 3 несовместимости.
- I'ᵈₖ = clip(Iᵈₖ + Σ effect × (8−L)/8 + синергии, 0, 100); Dᵈ = Σ wₖ I'ᵈₖ; D_avg = Σ popᵈ Dᵈ;
  **Score = 0.7·D_avg + 0.3·min(Dᵈ) − 1.0·N_crit**, N_crit — число пар «район×показатель» < 40.
- Правила: бюджет 100, ровно 5 решений, без повторов, ≤2 мер одного направления, район обязателен для мер типа «Район».
- Контрольные значения ТЗ воспроизведены: база 52.56; пример (M7, M8, M10 Нура; M12; M5 Сарыарка) — стоимость 95, Score 56.54; самый дешёвый допустимый набор — 61.

## 2. Почему формула корректна: композитные индикаторы (OECD/JRC, 2008)
Handbook on Constructing Composite Indicators задаёт шаги: теоретическая рамка → нормализация → взвешивание → агрегация → анализ робастности и чувствительности. Линейная агрегация компенсаторна (дефицит одного измерения гасится профицитом другого); когда цели равно легитимны, нужна непокомпенсаторная логика. Формула ТЗ — гибрид: линейная часть (0.7·D_avg) + роулсианский член «худшему району» (0.3·min D) + пороговый штраф (N_crit). Мы формулу не меняем, а добавляем обязательный по OECD шаг — анализ робастности: пересчёт при возмущении весов направлений ±20 % (с перенормировкой) и при равных весах; сценарий считается устойчивым, если выигрыш к базе положителен при всех возмущениях.

## 3. Равенство между районами
Разрыв «макс − мин», коэффициент вариации и коэффициент Джини по оценкам районов до/после; число критических значений. Это операционализация принципа «leave no one behind» (ЦУР 11).

## 4. Эффективность мер и Парето-фронт
Атрибуция вклада каждой меры в Score: 0.7 × взвешенный по населению вклад в D_avg + 0.3 × вклад в оценку слабейшего района + доля снятого штрафа (для показателей, поднятых выше 40); синергия делится между парой пополам. Сумма вкладов сходится с общим приростом Score (проверено тестом). Полный перебор 694 395 допустимых наборов даёт фронт Парето «стоимость ↔ Score» (11 недоминируемых точек от 61 у.е. → 55.67 до 98 у.е. → 57.24) и «лучший набор при бюджете ≤ X».

## 5. Индикаторы и ISO 37120:2018
Каждый показатель соотнесён с темой международного стандарта ISO 37120:2018 «Устойчивые города — индикаторы городских услуг и качества жизни» (111 индикаторов, 19 тем; сертификация WCCD) — см. `data/passports.json` и вкладку «Методология» в интерфейсе. Это делает модель переносимой на реальные данные акимата и сопоставимой с другими городами.

## 6. События
Опция ТЗ «моделирование неожиданных событий»: шок применяется к исходным показателям до мер (аварийная зима, смог, приток населения, паводок, жара), затем считается новая база и новый Score; пользователь перераспределяет 5 решений.

## 7. Роль AI (agentic)
- Объяснение сценария: LLM получает только результат расчёта (дельты, вклады, критические значения) и формулирует сильные стороны, риски, последствия и компромиссы; числа не считает.
- Агент-советник: запрос на естественном языке (RU/KZ) → цикл вызова инструментов (catalog → validate → simulate → improve → best_under_budget) → допустимый набор с обоснованием и трассой вызовов.
- Без ключа: детерминированные объяснения и разбор ограничений правилами — воспроизводимо на любой машине.
