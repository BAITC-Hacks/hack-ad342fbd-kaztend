# DISCLOSURE — сторонние компоненты и инструменты (п. 5.4.4–5.4.6 Положения HackAlem AI)

## Библиотеки (open source)
| Компонент | Лицензия | Назначение |
|---|---|---|
| fastapi, uvicorn, pydantic, starlette | MIT / BSD | HTTP API и раздача интерфейса |
| httpx | BSD | вызовы OpenAI Responses API |
| python-dotenv | BSD | загрузка `.env` |
| pytest | MIT | тесты |

Фронтенд — без сторонних библиотек (ванильный JS, SVG), внешние ресурсы не загружаются.

## Модели и AI-сервисы
| Сервис | Использование |
|---|---|
| OpenAI API, модель `gpt-6-sol` (Responses API, structured outputs, function tools) | объяснение сценария; агент-советник с инструментами. При отсутствии ключа — детерминированный режим |
| Claude (Anthropic) | AI-агент разработки: исследование методологии, архитектура, генерация кода и тестов, документация (разрешено п. 5.4.12 Положения) |
| OpenAI Codex | см. `docs/CODEX_LOG.md` |

## Данные
| Данные | Источник | Условия |
|---|---|---|
| Районы, показатели, мероприятия, формула Score | ТЗ спец-трека Astana Innovations (синтетический датасет организатора) | использован без изменений |
| Паспорта показателей (`data/passports.json`) | составлены командой по ISO 37120:2018 и открытым описаниям городских практик | собственная работа команды |
| `data/top_sets.json`, `data/pareto.json` | рассчитаны нашим кодом (`backend/optimizer.py`, `backend/analytics.py`) | воспроизводимы командой из README |
