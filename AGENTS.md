## Жёсткие правила
- Дедлайн 18:00 Астаны. Каждый час — рабочий коммит. Никакого большого рефакторинга после 16:45.
- Всё запускается одной командой по README (не запустилось по инструкции = команда выбывает).
- DEMO_MODE=true обязан работать БЕЗ API-ключа (записанные ответы в demo/recordings/).
- Секреты только через .env; в репозиторий — только .env.example.
- Интерфейс RU + KZ. Данные — реалистичные для Казахстана.
- Любой сторонний код/датасет/модель — запись в DISCLOSURE.md.
- Команда на Windows: не используй make; скрипты делай в двух версиях (.ps1 и .sh) или через python -m / npm run.

## Стек
- Backend: Python 3.11, FastAPI, openai SDK (Responses API, structured outputs, function tools).
  Модели: gpt-6-sol (основная логика), gpt-6-luna (дешёвые шаги), gpt-6-astra — только точечно.
- Frontend: простой React/Next или один index.html; панель «трасса агента» обязательна.
- Тесты: pytest tests/ — smoke-тест основного сценария, работает в DEMO_MODE.

## Принципы
1. Агент = план → инструменты → проверка → результат; трасса видна пользователю.
2. Детерминированный код там, где ошибка дорога; LLM — для понимания и генерации.
3. Human-in-the-loop на критичных действиях. 4. Модель умеет сказать «не знаю / нужна проверка».

## Как работать
Прочитай README.md, docs/ARCHITECTURE.md, docs/TZ_CRITERIA.md. Маленькие изменения, прогон тестов перед завершением.
Не переписывай работающие модули без просьбы. В конце задачи — резюме: что сделал / что проверил / что осталось.
